template<typename Key >
virtual CacheResult< Key > ICache< Key >::request ( const Key &  key)
pure virtual

Обрабатывает запрос к элементу и обновляет внутреннюю статистику.

Если происходит промах (miss) и кэш заполнен, алгоритм самостоятельно определяет и вытесняет наименее ценный элемент согласно своей модели.

Parameters
keyУникальный идентификатор запрашиваемого элемента.
Returns
CacheResult<Key> Структура с флагом попадания и данными о вытесненном ключе.

Implemented in TwoQ_Cache< Key >, ARC_Cache< Key >, LFU_Cache< Key >, LIRS_Cache< Key >, LRU_Cache< Key >, and Multi_Level_Cache< Key >.
