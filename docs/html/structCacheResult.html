Detailed Description

template<typename Key>
struct CacheResult< Key >

Базовый интерфейс для всех алгоритмов кэша.

Задает единый стандарт для обработки запросов. Позволяет создать любой алгоритм (LRU, LFU, ARC, LIRS) и прозрачно связывать их в многоуровневые системы (L0 -> L1 -> L2), где промахи верхнего уровня передаются на нижний.

Результат выполнения запроса к кэшу.
