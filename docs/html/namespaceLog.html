Уровни детализации вывода в консоль.

Enumerator

Критические ошибки (например, передача нулевого размера кэша).

Базовая статистика (hit rate, результаты бенчмарков).

TRACE 

Детальная информация (состояние директорий и очередей).

DEBUG 

Максимальная детализация (каждый хит/мисс, работа алгоритма).

Универсальная функция потокового вывода логов.

Использует C++17 fold expressions (выражения свертки) для безопасной распаковки произвольного количества аргументов и их вывода в std::cout без накладных расходов на рекурсивные вызовы шаблонов.
