Базовый интерфейс для всех алгоритмов кэша. 

Задает единый стандарт для обработки запросов. Позволяет создать любой алгоритм (LRU, LFU, ARC, LIRS) и прозрачно связывать их в многоуровневые системы (L0 -\/\texorpdfstring{$>$}{>} L1 -\/\texorpdfstring{$>$}{>} L2), где промахи верхнего уровня передаются на нижний.
