\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Key$>$\newline
class Two\+Q\+\_\+\+Cache$<$ Key $>$}
Алгоритм вытеснения 2Q (Two Queues). 

Решает проблему уязвимости классического LRU к полному сканированию данных. Разделяет память на три независимые очереди\+: IN (для новых элементов), OUT (теневой кэш для истории вытесненных) и VIP (для часто используемых). Элемент признается "{}горячим"{} и попадает в VIP только в том случае, если повторное обращение к нему произошло, пока его ключ находился в очереди OUT.
