\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Key$>$\newline
class LFU\+\_\+\+Cache$<$ Key $>$}
Алгоритм вытеснения LFU (Least Frequently Used). 

Выполнен на частоте обращений к элементам. При переполнении памяти вытесняет ключ, к которому обращались реже всего. Реализован со строгой асимптотикой O(1) для всех операций за счет использования двух хэш-\/таблиц\+: одна связывает ключ с его узлом, вторая группирует ключи по частоте их использования.
