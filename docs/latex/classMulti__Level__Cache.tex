\subsubsection*{template$<$typename Key$>$\newline
class Multi\+\_\+\+Level\+\_\+\+Cache$<$ Key $>$}
Реализация многоуровневой системы кэшей. 

Создает иерархию уровней (L0, L1, L2...) на основе входящего файла. Управляет данными между кэшами\+: при попадании на нижнем уровне элемент "{}поднимается"{} на самый быстрый уровень (L0), а вытесненные из L0 элементы "{}проваливаются"{} на уровни ниже, пока не покинут память окончательно.
